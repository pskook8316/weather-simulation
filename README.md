# 전국 일주일 날씨 시뮬레이션

전국 16개 도시의 7일 예보(Open-Meteo)를 불러와 지도·표로 보여주고,
예보를 평균으로 하는 몬테카를로 시뮬레이션(200회)으로 기온 불확실성 범위(10~90%)와
비 오는 날 수 분포를 계산합니다.

- 지도에서 날짜·시간(0~23시)을 골라 시간대별 날씨 확인, 도시별 24시간 기온/강수확률 차트
- 순수 HTML/JS 단일 파일(`index.html`), 빌드·API 키 불필요
- 시뮬레이션 모델: 리드타임에 비례해 커지는 오차 + 일간 자기상관(0.6) 랜덤워크
- 학습용이며 공식 예보가 아닙니다.
